# 《末班无站》剧透文档

> 本文包含全部真相、谜底、结局条件与可复现路径。建议至少通关一次后再阅读。

## 一、三个正式结局

| ID | 标题 | 类型 | 情绪与事件 |
| --- | --- | --- | --- |
| `survive` | **槐树胡同的灯** | 生还 | 你在第三声钟前离开异常，回到正常生活；但车、母亲与红毛线仍在雾里循环。 |
| `lost` | **第十三排乘客** | 迷失 | 你误判了井的规则，应了名字或坐回末班车，成为下一轮故事的乘客/引路人。 |
| `truth` | **把名字还给井** | 真相 | 你在收集车票、录音、证词与红毛衣后，把母亲的名字还给井，打破循环；代价是失去关于她的个人记忆。 |

正式结局只有这三个。游戏内有 **5 个结局节点**（包含同一结局的不同入口文本），但图鉴与封面只收录三个 ID：

- `ending_survive`：槐树胡同的灯（门墩调查线）
- `ending_survive_bus`：槐树胡同的灯（留在车上的另一条逃离线）
- `ending_lost_answer`：第十三排乘客（井边应名）
- `ending_lost_stay`：第十三排乘客（槐树胡同站台应名）
- `ending_lost_ride`：第十三排乘客（坐回十三排/在无知中返回车上）

## 二、真相梗概

1999 年 11 月 7 日深夜，13 路末班车因北新桥道路施工临时改行井儿胡同。胡同里有一口被遗忘的旧井，井盖早已朽坏，只盖着一层浮土。车右后轮压塌井盖，车身陷住，乘客下车。

九岁的林晚（乳名小满）在车上发烧，掉了一只红布鞋。母亲苏慧已经把孩子抱下车，又返回车上找鞋。井壁在那一刻坍塌。司机赵长顺抓住了她的手，她却把手抽回去，说“先抱孩子”。苏慧坠井身亡。

车队害怕违规绕行和安全生产责任，连夜用水泥封井，把事故报成“路面塌陷，无人员伤亡”。姥姥把林晚接走，告诉所有人孩子在车上睡着了、什么都没看见。林晚的记忆被发烧、恐惧和大人的谎言封住。

从那一年开始，每年十一月初七，13 路末班车会从终点站后头多开出一班。车沿着 1999 年那晚的路线循环，并在井儿胡同停靠。听见井底/槐树后有人叫自己的名字，若应声，就会把自己的名字交给井，成为车上的乘客，替这趟车继续开下去。赵长顺抱着旧收音机年年上车，却始终不敢叫出苏慧的名字。

林晚成年后成了电台后期，一直住在北新桥附近。那盘 1999 年的旧磁带和末班车把她重新带回循环。她最终发现：要结束循环，必须有人把属于苏慧的东西还到井边，并当众叫出她的名字“苏慧”——不是“妈”，不是“小满的妈”，而是她自己的名字。井要一个愿意永远记住她的人；打破循环的代价，是林晚把这份私人记忆交给井。

## 三、关键线索与变量

### 线索（`GameState.clues`）

| 线索 | 获取位置 | 作用 |
| --- | --- | --- |
| `ticket` 旧纸票 | 第一章 `c1_ticket` 选择“抽出来” | 1999.11.7 车票；真相结局必需 |
| `red-shoe` 红色童鞋 | 第一章 `c1_shoe` 选择“捡起来” | 母亲返回车上的原因；增加见证与结局余韵，不是硬门槛 |
| `doorstone` 缺角门墩 | 第三章 `c3_doorstone` 选择“摸一摸” | 确认童年住所与“小满”身份；不是硬门槛 |
| `radio` 调度录音 | 第四章 `c3_radio` 选择“按住老人的手” | 1999 年改行井儿胡同的调度记录；真相结局必需 |
| `sweater` 未收口红毛衣 | `c3_well_arrive` 自动获得 | 母亲留下的未完成遗物；真相结局必需 |
| `confession` 赵长顺的证词 | `c3_confession` 或 `c4_confession` | 事故经过与封井真相；真相结局必需 |
| `name` 苏慧 | 与 `confession` 同时获得 | 真名；情绪与真相的核心 |

### 变量（`GameState.flags`）

| 变量 | 来源 | 影响 |
| --- | --- | --- |
| `askedDriver` | 第一章问司机“到北新桥吗” | 立即获得赵长顺信任，影响录音后是否当场坦白 |
| `followedWoman` | 第一章跟着棕衣女人上车 | 另一种上车开场文本；不直接锁结局 |
| `returnedShoe` | 第一章把红鞋递还 | 获得红鞋线索并立即获得赵长顺信任 |
| `gotOff` | 第二章在井儿胡同下车 | 进入门墩/井台调查线；真相结局的前置 |
| `stayedBus` | 第二章选择留在车上 | 记录分支；只在留车线使用 |
| `answered` | 在井边或槐树胡同站台应名 | 直接进入迷失结局 |
| `confession` | 赵长顺坦白 | 真相结局的硬门槛之一 |

### 真相门槛

在第六章 `c5_001`，叙事数据检查：

```ts
allClues: ['ticket', 'radio', 'confession', 'sweater']
```

只有同时满足这四条线索，才会进入带“摇铃”选项的 `c5_gate_truth`；否则进入 `c5_gate_blind`。

- `sweater` 只在第二章选择下车后、到达井台时自动获得。留在车上永远无法获得。
- `radio` 只在 `c3_radio` 选择听完录音时获得。
- `ticket` 只在第一章选择抽出座椅缝里的纸票时获得。
- `confession` 有两条获取路线：
  1. 若 `askedDriver` 或 `returnedShoe`，听录音后直接进入 `c3_confession`。
  2. 若不满足信任条件，听录音后进入 `c3_radio_doubt`；在井边选择不出声，进入 `c4_silence`，此时若已有 `radio` 且没有 `confession`，赵长顺会在 `c4_confession` 坦白。
- 在井边应名会立即进入 `ending_lost_answer`，没有补救机会。

## 四、可复现路径

以下选择名称与游戏内按钮文本一致。

### 真相结局：把名字还给井（推荐路线）

1. 标题 → **开始游戏**
2. `c1_board`：**问一句：“师傅，这车到北新桥吗？”**
3. `c1_ticket`：**抽出来，借着窗外的光看清上面的字。**（获得 `ticket`）
4. `c1_shoe`：**捡起来，掸掉灰，递还给她。**（获得 `red-shoe`、`returnedShoe`；非硬门槛，但推荐）
5. `c2_off`：**跟下车。那个女人的毛衣上，有我很熟悉的味道。**（`gotOff`）
6. `c3_doorstone`：**把红线拨开，摸一摸缺角的门墩。**（获得 `doorstone`，非硬门槛）
7. `c3_radio`：**按住老人的手，听完这段广播。**（获得 `radio`）
8. `c3_radio_on` 因 `askedDriver` / `returnedShoe` 进入 `c3_confession`，获得 `confession`、`name`
9. `c4_answer`：**咬住舌尖，不出声。**
10. `c5_gate_truth`：**回到井边，把车票压在毛衣下，再登车摇响三下车铃。**

→ `c5_truth_action` → `ending_truth`《把名字还给井》

**最小真相路径**（不求当场坦白、不拿门墩/红鞋）：

- 开始 → 跟棕衣女人上车（`followedWoman`）→ **抽出来**（ticket）→ **假装没看见**（不拿红鞋）→ **跟下车** → **先跟上前面的女人**（不拿门墩）→ **按住老人的手**（radio）→ 进入 `c3_radio_doubt` → 井边 **咬住舌尖** → `c4_silence` 因有 radio 无 confession 而进入 `c4_confession` → 获得 confession/name → 最终 **回到井边，把车票压在毛衣下，再登车摇响三下车铃**。

### 生还结局 A：槐树胡同的灯（调查线）

前置同真相路线，拿到/没拿齐线索均可：

1. 进入 `c5_gate_truth` 或 `c5_gate_blind`
2. 选择 **攥紧车票，朝槐树胡同的灯跑。** 或 **捂住耳朵，朝槐树胡同的灯跑。**
3. → `ending_survive`《槐树胡同的灯》

余韵会依据你是否拿过车票/红鞋等线索保留；正式结局仍为 `survive`。

### 生还结局 B：槐树胡同的灯（留在车上线）

1. 第一章正常上车，拿不拿票/鞋不限
2. `c2_off`：**坐在车上。这里不对劲，离司机近一点更安全。**
3. `c2_stay_again`：**坐回十三排，把眼睛闭上。**
4. `c2_stay4` 到达槐树胡同后，`c2_stay_final` 选择 **不看车门，沿着槐树胡同的路灯跑。**
5. → `ending_survive_bus`《槐树胡同的灯》

这条线说明：即使没有理解真相，也有机会活下来；但余韵里仍有人被留在循环中。

### 迷失结局 A：第十三排乘客（应名）

1. 正常进入第二章并选择 **跟下车**
2. 走到井台，听完/不听录音均可
3. 在 `c4_answer` 选择 **应一声：“妈，我在。”**
4. → `ending_lost_answer`《第十三排乘客》

### 迷失结局 B：第十三排乘客（站台应名）

1. 第一章上车
2. `c2_off`：**坐在车上。这里不对劲，离司机近一点更安全。**
3. `c2_stay_again`：**坐回十三排，把眼睛闭上。**
4. `c2_stay4` 后，`c2_stay_final` 选择 **应一声，走下车，去吃那顿不存在的饺子。**
5. → `ending_lost_stay`《第十三排乘客》

### 迷失结局 C：第十三排乘客（坐回十三排）

1. 第一章上车
2. `c2_off`：**坐在车上。**
3. `c2_stay_again`：**坐回十三排。**
4. `c2_stay_final`：**坐回十三排，抱住膝盖，等车门自己关上。**
5. → `c2_lost_loop` → `ending_lost_ride`《第十三排乘客》

另一条到达同一节点的路：在调查线集齐真相门槛时如果故意放弃，于 `c5_gate_truth` 选“跑”会生还；若未集齐门槛，在 `c5_gate_blind` 选择 **回到车上，坐回十三排。** 会经 `c5_lost_action` 进入 `ending_lost_ride`。

## 五、早期细节如何回收

| 早期细节 | 后续解释/反转 |
| --- | --- |
| 座椅缝里的 1999.11.7 纸票，背面“小满，别怕。妈在。” | 母亲最后一晚留下的票；小满就是主角；纸票是真相仪式的一部分。 |
| 棕衣女人掉落的红色童鞋，鞋底绣“满” | 主角小时候的鞋；母亲返回车中就是为了拿另一只鞋。 |
| “井儿胡同”这个不存在的站名 | 1999 年事故后被从公交线路图抹去的临时绕行站；只有循环车仍停。 |
| 站牌“北新桥”缺了“桥”字 | 线路在事故后不再真正抵达北新桥；站名/记忆都被磨损。 |
| 缺角门墩与“小满 九岁 九九·十”刻痕 | 主角的童年家；确认她的身份和失忆不是幻觉。 |
| 旧收音机里的调度录音与“车上还有个孩子，叫林晚” | 1999 年真实调度；赵长顺保留录音并年年上车，是创伤与赎罪。 |
| 未收口的红毛衣与“袖子收好了” | 母亲遇难前给主角织的十岁生日毛衣；真相仪式中归还井，最后在真相结局里被母亲“收好”。 |
| 远处第三声钟 | 循环关闭的时限；也是“不该再留在车上”的民俗式规则，不是装饰。 |
| 赵长顺说“你妈不会包饺子，她那天买的是挂面” | 循环/井会仿造亲人的声音与家的气味；应名等于把名字交出去。 |

## 六、设计上的自洽说明

- 井不是“许愿机”，它收集的是名字和记忆。应名者会被留下来成为循环的一部分；说出死者的真名并归还遗物，才能把名字从井里“赎”出来。
- “别应名字”是赵长顺根据多年经验总结的活命规则；“到槐树胡同、第三声钟前下车”是逃离规则。
- 真相路线故意违背“别在井儿胡同下车”的表面警告，因为老人只知道如何让人活下来，不知道如何让死者离开。
- 打破循环必须付出“记忆”代价：井要一个愿意记住的人，林晚把母亲从自己的私人记忆中交还给公共记录。她记得“苏慧”这个名字和事实，却记不起母亲的脸与声音。
- 生还结局不是惩罚；林晚确实离开了车。只是循环仍在，她保留了一截红线和不断出现的余韵。
- 迷失结局不是单纯死亡：应名者会成为下一轮的乘客或引导者，继续维持循环，因此三个结局在事件、揭示与情绪上都不同。

## 七、自动化校验与调试

没有在正式游戏界面暴露调试入口。

```bash
npm run test:story
npm run test:save
npm run build
```

- `scripts/validate-story.ts`：检查节点/选项指向、条件变量、全部节点可达、三个结局可达、每条路线的选择数、汉字数，并输出各结局示例路径。
- `scripts/validate-save.ts`：检查存档恢复、损坏/版本不兼容、新周目保留图鉴等。
- `scripts/browser-check.mjs`：生产预览的浏览器级三结局流程、历史、设置、自动存档、离线刷新、手机溢出检查。运行前需另开终端执行 `npm run preview`。

最新校验结果：55 个节点全部可达；216 条完整路线；单路线 6,029—9,518 汉字；6—9 次有意义选择；三结局可达。更多环境与未验证项见根目录 README。
